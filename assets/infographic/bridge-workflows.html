Zo-LongHorizon · workflows

Two doors in. One bridge does the work.

A scheduled automation and a chat request take the same path: the Zo turn launches and returns in about a second, a detached agent CLI owns the loop for as long as the job needs, and Zo comes back in as the MCP tool server that sends the email, texts the result, and writes the files.
